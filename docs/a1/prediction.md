# A1 测量前预测

记录时间：2026-11-09T20:15:59.136483+08:00

配额 0.5 核、周期 100 ms，整个 cgroup 每周期共享 50 ms 的 CPU 时间。假设忙线程可同时在两个逻辑 CPU 上运行，1 个线程预计每周期运行 50 ms、被停 50 ms；2 个线程预计平均各运行 25 ms、被停 75 ms。持续跑满时，实际用核预计约 0.50，被节流周期比例接近 100%。本机有 2 个可用逻辑 CPU，未设置 GOMAXPROCS/GODEBUG 覆盖；Go 对 cgroup 配额向上取整且默认并行度在可用 CPU 不少于 2 时不低于 2，因此预计 GOMAXPROCS=2。调度开销、周期边界与按 CPU 累计计数可能使实测停顿与理想算术有小幅偏差。
