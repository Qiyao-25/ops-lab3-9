# O1 测量前预测

2026-11-12T19:44:31.296174+08:00

预测：保持 A3 的 MemoryMax=200MiB、MemorySwapMax=0、默认 GOGC、不限报表并发，每请求分配 8MiB 并保持 500ms。10/20/30 请求每秒的平均并发约为 5/10/15。默认 GC 对照预计在 20 请求每秒阶段 OOM；GOMEMLIMIT=170MiB 预计更早触发 GC，降低峰值内存，使 20 阶段更可能存活，但会增加 GC 频率和 CPU 代价。30 阶段若活跃对象及运行时开销已逼近硬限制，仍可能 OOM（主预测推迟到 30 阶段被杀）；也可能本次随机负载下全程存活，不能把软限制当成不被杀的保证。两组使用同一二进制、默认种子和相同负载；共用的 10 阶段用于比较 GC/CPU。额外以相同频率采集两组 /metrics，保留死亡前计数。GC CPU 为运行时估计值，不等于精确进程 CPU 分解。
