# A3 测量前预测

2026-11-10T10:50:55.311899+08:00

每请求实际分配 8 MiB 并保持至少 0.5 秒。用 Little 定律估计到达率 10、20、30 请求/秒时平均在途数分别为 5、10、15；这不等于最大值。Poisson 到达无确定的并发上界，按均值加 3 倍标准差粗估短时高位约为 12、20、27 个，作为测量前预测而非硬上界。启动后空闲 RSS 实测 8.4375 MiB，仅计算活跃缓冲区时平均 RSS 粗估约 48.44、88.44、128.44 MiB；考虑 GOGC=100 下 GC 前的堆增长余量，用基线加 2 倍缓冲区估算约 88.44、168.44、248.44 MiB。GC 的 2 倍是容量估算，不是 RSS 的精确上界。预测 10 请求/秒通常可存活，20 请求/秒可能因随机并发峰值和尚未回收的对象提前 OOM（主预测在第二阶段被杀），30 请求/秒风险更高。MemoryMax=200M、MemorySwapMax=0，预期结果为 oom-kill/SIGKILL。基线压测按指导书原命令运行，若被杀后 loadgen 提前停止，保留其实际输出，不伪造后续阶段。改法一以 20 请求/秒为目标，测得并发峰值后结合 GC 余量计算新上限并再加约 10% 安全余量；改法二保持 200 MiB 上限，按并发上限×8 MiB×2+基线<200 MiB 选择 report-max，超额请求预计快速返回 503，以牺牲接收率保护进程。
