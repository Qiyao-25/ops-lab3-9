# O6 测前预测

服务留在主机 A。同机组在 A 运行 loadgen 和 lbd，跨机组将两者移到同 VPC 的主机 B。两轮均使用相同 enrolld 二进制、一个后端、25% CPU 配额、60 请求/秒持续 90 秒、同一默认随机种子和 lbd 健康检查设置。

预计跨机增加 lbd 到后端的网络往返，p50 和 p99 可能略升。主机 A 少了压测和转发的开销，尾延迟也可能下降。负载低于本组 B0 的容量线，预计两组成功吞吐接近 60 请求/秒、错误接近零。比较客户端延迟、错误、成功吞吐和发送滞后，分别记录拓扑与主机条件。跨机时主机 A 的 8080 入站仅允许主机 B 的私网 IP，测完撤销。
